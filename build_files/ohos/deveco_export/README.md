# Portable DevEco export/assembly candidate

Status: **PREPARED**. This namespace is a new implementation, not an assembled project or an accepted native/HAP build. It never compiles, signs, installs, starts a server, or downloads. Parent-owned core link, actual assembly, DevEco compilation, final signing, installed namespace/Ark callbacks, picker/lifecycle/WSI/GPU and no-spawn acceptance are NOT_RUN. Do not call a core-less host template a complete Blender project.

The existing host151, compiled inputs, SDK, accepted prefixes and frozen builders are read-only inputs. CLI entrypoints verify this namespace's `inputs.lock.json`. Outputs are absent/new only. Native signed bytes are never stripped, renamed to repair SONAME, patched, or re-signed by this exporter. The original Blender source/tpr/licenses, support trees and offline caches are copied once into a private output only when assembly is actually authorized and supplied with real inputs. Source hashing is deferred to a stable caller-selected snapshot; short review tests do not read/copy the giant source or ELF payload.

## Two phases

`assemble` requires a real signed `libblender_core.so`, successful final link/sign evidence, real creator ABI2 source/header/export bindings, a complete source inventory, selected native93 and development-2 pure8 receipts, explicit installed native/ETS SDK26 and tools, actual notices, and pinned offline caches. Missing real core rejects before payload work. Default assembly also rejects missing source-rebuild stages. An explicit `--allow-prepared-rebuild` can publish only `PREPARED_HOST_LINK_PENDING` with its material source rebuild gaps recorded and `complete_portable_project=false`.

`audit-host` later consumes the actual final signed CMake/DevEco host output. It verifies every sealed export file/link, exact source/header/CMake bindings, actual CMake cache source/core/compiler/STL paths, all four C++17 compile commands, link command/log and signer/log hashes, final host ELF hash/exports/NEEDED, and chosen SDK C++ runtime closure. It writes a NEW immutable `FINAL_NATIVE_INPUTS_AUDITED_HAP_NOT_RUN` receipt. It never copies host into `entry/libs` beside a CMake output of the same name, never changes sealed assembled libraries, and never reuses an old native PASS after a rebuild/re-sign. `.codesign` presence is only one structural check; actual link/sign logs, tool hashes, exact final bytes and installed loader acceptance remain necessary. This does not independently authenticate a signing log or cryptographically verify a HAP signature.
