# Geometry builder attribution and license boundaries

Builder/signing/source/audit utilities adapt the Blender OHOS core/volume GPL-2.0-or-later utilities into this independently sealed namespace. Input paths and original SHA-256 are recorded in `input-lineage.json`. No import executes another mutable namespace. The purpose-built geometry tests preserve the original accepted work tests and add multiprecision serialization, shader compilation and raw mesh export checks. Those old test/recipe hashes are provenance only; they confer no new native acceptance.

The byte-identical Blender `FindGMP.cmake` and `FindOpenSubdiv.cmake` copies retain the Blender Authors copyright and BSD-3-Clause license notices. New local builder/test adaptations are GPL-2.0-or-later. The complete original third-party archives retain every source copyright/header/license, including GMP GPLv2/LGPLv3 alternatives, Pixar LICENSE and NOTICE, manifold Apache2/linalg/SVD notices, and TBB Apache2/third-party notices. Notice mirrors carry source-path and SHA-256 provenance. Licensing is not inferred solely from Blender's short versions-file labels.

No upstream source archive is modified, filtered or repacked. The only source adaptation is the separate three-file GMP patch; full before/after snapshots and SHA-256 preserve its lineage. Static TBB is the explicitly accepted Blender profile, with upstream's unsupported-static-mode warning retained in its original sources. GMP assembly remains disabled in the accepted ARM64 correctness profile; multiprecision APIs remain enabled. ShaderC/SPIRV tools are a declared already accepted test-only source closure, not a runtime dependency added to OpenSubdiv's public package. GNU Make4.4.1 is a caller-declared signed binary build prerequisite backed by the existing complete formal GNU Make source archive. SDK/compiler/Python/system tools are declared external inputs.

Native source acceptance excludes Blender/HAP release acceptance, GPU dispatch and PIC module dlopen/static C++ runtime ownership. No fresh native compilation has been performed during this source-only handoff.
