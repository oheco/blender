Complete upstream originals for OpenSubdiv v3_7_0, GMP6.3.0 and manifold3.5.2 are stored as ordinary <=32MiB parts in the three new `tpr/sources` entries. The original archive SHA-256/size/URL, complete source inventories and unchanged notice mirrors are recorded in `provenance.json` and `builder/sources.lock.json`. TBB v2022.3.0 reuses its existing immutable formal archive and must be compiled from source in every new geometry root. GNU Make4.4.1's existing complete formal source entry backs the explicitly declared accepted signed tool prerequisite.

`builder/README.md` provides the entire CLI and independently sealed offline source/native acceptance contract. `builder/inputs.lock.json` seals this namespace, the selected registry originals/notice mirrors, exact GMP before/after snapshots and tool-source provenance. Only the separately recorded three-file GMP patch modifies source bytes. No generated foreign platform configuration or old/partial TBB prefix is consumed.

Short source/copy/metadata/negative/read-only native planning receipts are delivered separately in the new work handoff. They verify source replay and declared native tools; they do not confer native library acceptance. **Fresh native full, Blender modifier and installed HAP acceptance are NOT RUN.** Full requires actual new source builds, genuine GMP native probes/upstream tests, meaningful geometry/real GLSL consumers, native artifact/PIC/metadata audits and moved Unicode/space CMAKE+PC consumers. The shader test prerequisite must already have its own genuine complete source-closure acceptance; the portable project can build the formal GPU namespace first.
