# Complete offline color dependency sources

The 14 new original color sources are registered under tpr/sources; all 21 color
and prerequisite source inventories and original notice declarations are sealed
by builder/sources.lock.json and builder/inputs.lock.json. Seven identical
existing prerequisite entries are reused without duplication or mutation.

The portable native candidate is builder/builder.py; builder/README.md documents
its complete selected source closure, exact patches, explicit native tools,
metadata/ABI/sign/PIC/runtime/migration gates and the distinction between short
source verification, historical native evidence and a future fresh full run.

Original archives remain pristine and reconstructable. Only separately sealed
original evidenced patches alter new extracted private source trees. No main
Blender source or existing core/volume builder is changed by this namespace.
