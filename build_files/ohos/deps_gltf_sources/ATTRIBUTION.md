The optional upstream Git submodules are not claimed as present.

The actual wrapper implementation is Blender's `intern/draco_bridge/intern` and `intern/meshoptimizer_bridge/intern`. Original wrapper licensing is retained: Draco bridge sources Apache-2.0; meshoptimizer bridge sources GPL-2.0-or-later. Only the copied standalone Draco encoder/decoder translation units receive explicit missing standard header includes. The sealed patch records carry exact original and adapted hashes; all forward and reverse checks run in newly owned private source copies. The existing repository sources remain untouched.

The source guard and private ownership/receipt design follow the repository's `deps_python_resources_sources/source_guard.py` and `deps_volume_sources/builder/io_utils.py`. The compiler signing launcher, native platform information and native host observation files are copied from `deps_core_sources/builder` (GPL-2.0-or-later). The toolchain logic is adapted from that builder and retains actual Clang/SDK/preprocessor checks without compiler identity, HAVE, native-test or cross status overrides.

The acceptance implementation under `acceptance` is newly authored and its files retain their declared Apache-2.0 SPDX headers. It reads the sealed Blender API baseline and does not emulate bpy or upstream codecs. The separately recorded addon error cleanup patch is a candidate against the real Blender loader; it is not automatically applied to formal source or to the installed baseline addon.
