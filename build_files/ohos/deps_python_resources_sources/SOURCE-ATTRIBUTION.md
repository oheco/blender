# Source and recipe attribution

All upstream source bytes are pristine official PyPI sdists. This namespace contains no vendored snippets in place of full source: `tpr/sources` stores every original archive byte as ordinary Git parts; the eight-input lock seals their official URLs, complete hashes/sizes, original metadata, source inventories, and complete notice mirrors. `charset-normalizer-3.4.1` reuses its unchanged existing registry entry after exact SHA/size/name/version/URL checks. Its additional original `data/NOTICE.md` is mirrored here without changing that old entry.

The bounded extraction approach derives from the already reviewed local security-candidate `prepare.py` (SHA-256 `4539dc78d7fed5494213866bceb116e202c59df6701a5544fdeb2f3a5947043e`) and `source_guards.py` (`4a24af7b6d2131e2702b63f5d7aa52825490d9ecb128a526fe5c137180a6185d`). This portable implementation is newly written for Blender's GPL-2.0-or-later recipe namespace. It removes fetching and evidence-path dependencies, verifies all members before extraction, checks case collisions in implicit directory prefixes and file/directory collisions, and never applies archive ownership/modes. It does not copy the candidate's whole work script. The existing Blender `build_files/ohos/vendor_archive.py` GPL-2.0-or-later implementation remains unchanged and is consumed by its public verify/materialize functions; the lock seals its exact bytes.

Upstream notices and copyrights are copied in full, not summarized: Requests Apache-2.0 LICENSE and NOTICE; urllib3 MIT LICENSE.txt; idna BSD-3-Clause LICENSE.md; certifi's original MPL notice LICENSE and unmodified publisher CA bundle; charset-normalizer MIT LICENSE and data NOTICE.md; cattrs MIT LICENSE; attrs MIT LICENSE and docs/license.md; typing_extensions complete PSF license/history LICENSE. Their exact file hashes and sizes are in the lock. The certifi LICENSE is preserved exactly as shipped, including its reference to the Mozilla license; no fabricated or substituted license text is used. Copyright statements embedded in all source files are retained in the complete source archives and in every copied runtime package file.

The official PyPI JSON metadata bodies are mirrored unmodified. Original sdist PKG-INFO is copied byte-for-byte to runtime dist-info/METADATA. Generated INSTALLER only identifies this source-copy assembler; there is no synthetic upstream wheel metadata, patched source, optional codec build, or temporary network dependency.
